# Руководство пользователя библиотеки poisson-fuzzy

## 1. Назначение

Библиотека решает две задачи:

1. **Моделирование нечётких величин**: для заданного λ строится α-срез
   {x : P(x; λ) ≥ τY} распределения Пуассона. Результат представляется
   как треугольное нечёткое число (A, (A+B)/2, B).
2. **Кластерный анализ** набора таких нечётких величин методом K-means
   по признакам (C, R, M) — центр, относительная ширина, масса покрытия.

Порог **τY = thresholdRatio × max P(x)** — постоянный для всего набора,
поэтому на графике это одна горизонтальная линия.
